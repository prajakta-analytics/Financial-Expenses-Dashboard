# Financial Expenses Analysis Dashboard

## 📊 Project Overview
This Power BI dashboard analyzes personal financial expenses and income across different categories, quarters, and account types.

## 🔍 Key Insights
- Monthly Income vs Expense comparison
- Expenses by category and sub-category
- Debit analysis by account type
- Quarter-wise expense filtering
- Company-wise expense distribution

## 🛠 Tools Used
- Power BI
- Excel / CSV
- GitHub
